🌱 Guide Complet des Commandes de Base

Retrouvez toutes les commandes indispensables pour configurer Git, démarrer un projet et gérer l'historique de vos fichiers.

A. Configuration Initiale de l'Identité

1. Configurer le Nom d'utilisateur

Définit le nom qui sera associé de manière permanente à chacun de vos enregistrements (commits).

git config --global user.name "VotreNom"

2. Configurer l'Adresse E-mail

Associe votre adresse e-mail à vos modifications. C'est l'identifiant obligatoire utilisé par GitHub.

git config --global user.email "votre@email.com"

3. Configurer la Branche par Défaut

Force Git à nommer la branche principale main au lieu de l'ancien nom par défaut master.

git config --global init.defaultBranch main

4. Vérifier les Paramètres

Affiche la liste complète de toutes les configurations actives sur votre environnement informatique.

git config --list
B. Création et Clonage de Dépôts

5. Initialiser un Dépôt

Crée un nouveau dépôt Git local vide. Cela génère le dossier masqué invisible .git à la racine du projet.

git init

6. Cloner un Projet Existant

Télécharge une copie complète d'un dépôt déjà existant sur GitHub directement sur votre ordinateur.

git clone https://github.com/utilisateur/depot.git
C. Le Cycle de Suivi et d'Enregistrement (Workflow)

7. Vérifier le Statut des Fichiers

Indique avec précision quels fichiers sont modifiés, lesquels attendent d'être enregistrés (Staging area), et lesquels ne sont pas encore suivis.

git status

8. Ajouter un Fichier Spécifique

Ajoute un seul fichier ciblé à la zone de préparation (Staging Area) avant l'enregistrement.

git add mon_fichier.txt

9. Ajouter TOUS les Changements

Envoie l'intégralité des fichiers créés ou modifiés du dossier de travail vers l'index de préparation.

git add .

10. Enregistrer l'Instantané (Commit)

Sauvegarde définitivement la version des fichiers dans votre historique Git local avec un texte d'explication.

git commit -m "Ajout de la structure de base"

11. Consulter l'Historique

Affiche la liste chronologique complète de tous les commits validés sur le projet (avec auteurs, dates et codes SHA-1).

git log

Testez vos compétences Débutant !

Répondez aux questions suivantes pour voir si vous maîtrisez les bases.

1. Quelle commande permet d'initialiser un projet Git dans le dossier courant ?

  • git start
  • git init
  • git setup

2. Comment ajouter tous les fichiers modifiés d'un coup à la zone de Staging ?

  • git add -all
  • git add .
  • git commit --all

3. Quel est le rôle de la commande "git log" ?

  • Voir l'historique complet des commits passés
  • Se connecter à son compte en écrivant un identifiant
  • Supprimer les erreurs commises dans le code

4. Quelle commande permet de lister toutes les configurations actives de son profil ?

  • git config --show
  • git status --list
  • git config --list

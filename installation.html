⚙️ Guide d'Installation et Authentification

Installez Git sur votre machine de développement et configurez vos accès sécurisés (Token et clés SSH) pour communiquer avec GitHub.

1. Installation de Git

Sur Windows

  1. Téléchargez l'installateur officiel sur git-scm.com.
  2. Lancez le fichier exécutable .exe téléchargé.
  3. Suivez les étapes de l'assistant en laissant les options par défaut (notamment l'utilisation de Git Bash comme terminal recommandé).

Sur Linux (Ubuntu / Debian)

Ouvrez votre terminal système et exécutez la commande suivante pour installer Git via le gestionnaire de paquets Advanced Package Tool :

sudo apt update && sudo apt install git -y

Sur macOS

La méthode la plus simple consiste à utiliser le gestionnaire Homebrew dans votre terminal d'origine :

brew install git

Vérification de l'installation

Pour vous assurer que Git est correctement installé et accessible globalement, ouvrez un terminal (ou Git Bash) et tapez :

git --version
2. Sécurisation et Authentification GitHub

Méthode 1 : Personal Access Token (Recommandée)

  1. Connectez-vous sur votre compte GitHub.
  2. Allez dans Settings > Developer Settings > Personal Access Tokens > Tokens (classic).
  3. Cliquez sur Generate new token, donnez-lui un nom, cochez la case "repo" (obligatoire pour gérer vos projets) et générez-le.
  4. ⚠️ Copiez précieusement ce token, il ne s'affichera plus jamais !

Sauvegarde permanente du Token sur votre PC : Pour éviter de retaper le token à chaque envoi de code, activez la mise en mémoire automatique :

git config --global credential.helper store

Méthode 2 : Authentification par clé SSH (Avancée)

Étape A : Générez une nouvelle paire de clés de cryptage asymétrique RSA (remplacez par votre e-mail) :

ssh-keygen -t rsa -b 4096 -C "votre@email.com"

Étape B : Affichez et copiez le contenu textuel complet de votre clé publique générée :

cat ~/.ssh/id_rsa.pub

Allez ensuite sur GitHub dans Settings > SSH and GPG keys > New SSH Key, collez ce texte et validez.

Validez votre Configuration

Vérifiez vos connaissances sur la mise en place de l'environnement de développement.

1. Quelle commande permet de vérifier si Git fonctionne et de connaître sa version installée ?

  • git check
  • git --version
  • git info

2. Quel privilège (scope) minimal doit impérativement posséder un Token sur GitHub pour manipuler vos dépôts ?

  • admin
  • user
  • repo

3. Quel terminal Windows est officiellement recommandé et installé par défaut avec Git ?

  • L'invite de commandes CMD
  • Git Bash
  • PowerShell

4. Quel fichier de clé devez-vous copier et ajouter sur votre profil GitHub pour l'accès SSH ?

  • La clé publique (id_rsa.pub)
  • La clé privée (id_rsa)
  • Le fichier de configuration globale

# Product Backlog

## Vision

Créer une plateforme de gestion de projets GitHub destinée aux étudiants, enseignants et équipes académiques, afin de centraliser les tâches, la documentation et le pilotage des livrables.

## Backlog produit

### 1. Gestion du projet
- En tant qu'équipe de projet, je veux un tableau de bord centralisé pour suivre l'avancement.
- En tant que chef de projet, je veux visualiser les KPI du projet.

### 2. Gestion des tâches
- En tant qu'étudiant, je veux organiser mes tâches par sprint.
- En tant qu'équipe, je veux identifier les tâches prioritaires.

### 3. Documentation
- En tant qu'utilisateur, je veux consulter la documentation technique et pédagogique.
- En tant que membre, je veux retrouver les guides de mise en route.

### 4. Présentation soutenance
- En tant que présentateur, je veux afficher une vue claire de la roadmap.
- En tant que jury, je veux comprendre rapidement les livrables et critères de réussite.

### 5. Expérience utilisateur
- En tant qu'utilisateur, je veux une interface moderne et réactive.
- En tant que visiteur mobile, je veux un affichage propre sur petit écran.

## Priorisation

- Priorité 1 : Dashboard, KPI, roadmap, documentation
- Priorité 2 : UX et finition visuelle
- Priorité 3 : Extension métier et intégration de données réelles

# Guide d'utilisation

## Vue d'ensemble

GitHub-Schools est une plateforme de pilotage académiques et de suivi de projets orientée GitHub. Elle a pour but d'aider les étudiants à présenter leurs projets de manière claire, structurée et professionnelle.

## Navigation

L'interface principale se compose de cinq éléments clés :

- Header de navigation
- Cartes de KPI
- Liste des tâches
- Timeline de roadmap
- Section de membres et de livrables

## Fournir une démonstration

1. Démarrer le projet avec `npm run dev`.
2. Ouvrir l'application.
3. Vérifier le tableau de bord complet.
4. Identifier les indicateurs clés et les livraisons attendues.
5. Présenter la documentation dans le dossier `docs/` lors de la soutenance.

## Points d'attention

- Le projet est construit pour un usage démonstratif et professionnel.
- L'architecture est extensible pour ajouter des modules de gestion des étudiants, des enseignants ou des projets.
- Les fichiers de données peuvent être remplacés par des API réelles dans une version de production.

## Bonnes pratiques

- Travailler à partir d'un environnement propre.
- Garder la documentation à jour au fil du projet.
- Utiliser la structure `src/` pour toute logique d'interface.
- Ne pas modifier directement les fichiers de build sans justificatif technique.

Espace Exercices & Code Labs

Pas de QCM ici ! Tapez la commande Git exacte demandée pour résoudre chaque scénario technique réel.

Mission 1 : Résolution de Conflit Urgent
Intermédiaire
Scénario : Après un git pull, Git signale un conflit de fusion dans le fichier app.js. Vous ouvrez le fichier, vous nettoyez les lignes et résolvez le problème à la main.
Quelle commande tapez-vous immédiatement pour marquer le fichier résolu et le préparer pour le commit de fusion ?
💡 Indice : C'est la commande de base pour ajouter un élément modifié à la Zone de Staging.
$
Mission 2 : Changement de branche (Remisage)
Intermédiaire
Scénario : Vous travaillez sur un nouveau design pas encore stable. Votre enseignant vous demande de changer immédiatement de branche. Vous ne voulez pas faire de commit brouillon.
Quelle commande vous permet de mettre de côté vos modifications non validées dans une cache temporaire ?
💡 Indice : En anglais, ce terme signifie masquer ou mettre de côté dans une boîte.
$
Mission 3 : Annulation Critique Radicale
Avancé
Scénario : Votre dernier commit contient un bug majeur destructeur et des mots de passe. Vous décidez de l'effacer totalement.
Quelle commande permet de reculer d'un commit en effaçant définitivement toutes vos modifications locales ?
💡 Indice : Utilisez un reset avec l'option la plus stricte (flag) et ciblez le commit précédent (HEAD~1).
$
Mission 4 : Correction d'un Message de Commit
Débutant
Scénario : Vous venez de valider un commit local avec le message "Ajou de la page". Vous constatez une faute de frappe honteuse.
Quelle commande vous permet de modifier directement le message textuel de ce tout dernier commit sans en créer un nouveau ?
💡 Indice : On utilise une option spéciale appelée "amendement".
$
Mission 5 : Raccourci de Branchement
Débutant
Scénario : Vous devez développer un système de paiement. Vous voulez aller vite.
Quelle commande unique permet de créer la branche nommée feature-payment ET de basculer dessus immédiatement ?
💡 Indice : Utilisez la commande habituelle de déplacement complétée par l'option -b.
$
Mission 6 : Inspection des Serveurs Distants
Intermédiaire
Scénario : Vous reprenez un projet étudiant sur votre PC mais vous ne savez plus si ce dossier local est correctement lié à votre compte GitHub ou à celui de votre binôme.
Quelle commande vous permet de lister et vérifier de manière détaillée les URL de dépôts distants configurées ?
💡 Indice : C'est une déclinaison de la commande git remote complétée par l'option de verbosité (-v).
$
Mission 7 : Livraison Finale (Tagging)
Avancé
Scénario : Votre application web est terminée, testée et parfaitement stable. Votre enseignant demande de figer le code actuel pour marquer l'examen.
Quelle commande vous permet de poser un tag annoté nommé v1.0 avec le message explicatif "Version Finale" ?
💡 Indice : La structure requise est : git tag -a [nom] -m "[message]". Respecte bien les espaces.
$

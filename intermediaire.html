🌿 Branches, Gestion d'Équipe & Dépôts Distants

Guide complet pour maîtriser le travail parallèle en équipe et la synchronisation avec GitHub sans écraser le travail des autres.

A. Maîtrise Avancée des Branches Locales

1. Lister les branches locales

Affiche toutes les branches créées sur votre machine. La branche sur laquelle vous vous trouvez est marquée par un astérisque *.

git branch

2. Créer une nouvelle branche

Crée une nouvelle ligne de développement (ex: feature-login) pour coder une fonctionnalité de manière isolée.

git branch feature-login

3. Basculer sur une branche (Checkout)

Permet de vous déplacer sur la branche sélectionnée pour y effectuer vos modifications.

git checkout feature-login

4. Raccourci : Créer ET basculer instantanément

Crée la branche demandée et vous déplace dessus immédiatement en une seule ligne de commande.

git checkout -b nouvelle-branche

5. Fusionner une branche (Merge)

Fusionne les commits de la branche spécifiée (ex: feature-login) dans la branche active où vous êtes positionné (généralement main).

git merge feature-login

6. Supprimer une branche locale sécurisée

Supprime une branche locale uniquement si elle a déjà été entièrement fusionnée avec la branche principale.

git branch -d nom-de-la-branche
B. Synchronisation avec le Dépôt Distant (GitHub)

7. Connecter son PC à un dépôt GitHub

Établit un lien de connexion nommé origin entre votre dépôt local sur PC et l'adresse URL de votre serveur GitHub.

git remote add origin https://github.com/utilisateur/projet.git

8. Vérifier la liaison avec le serveur

Affiche les adresses URL distantes configurées pour l'envoi (push) et la réception (fetch) de vos fichiers.

git remote -v

9. Envoyer ses commits locaux (Push)

Téléverse vos enregistrements locaux vers la branche principale de GitHub. Le drapeau -u lie les branches pour les prochains envois.

git push -u origin main

10. Pousser une branche spécifique

Envoie une branche secondaire de travail directement sur GitHub pour la partager avec votre binôme.

git push origin feature-login

11. Récupérer et Fusionner (Pull)

Télécharge les dernières modifications poussées par d'autres développeurs sur GitHub et les fusionne automatiquement dans votre code actuel.

git pull
C. Comparaison et Statuts Courts

12. Statut en version courte

Donne un aperçu très compact et rapide de l'état de vos fichiers (pratique lorsque vous avez beaucoup de modifications).

git status -s

13. Comparer deux branches

Affiche précisément toutes les lignes de code qui diffèrent entre deux branches distinctes avant de lancer une fusion.

git diff main..feature-login

Évaluation Intermédiaire

Validez vos acquis sur les branches et l'interaction avec GitHub.

1. Quelle commande permet de créer ET de se déplacer sur une branche en une seule action ?

  • git branch -new
  • git checkout -b ma-branche
  • git switch --create

2. Vous êtes sur "main". Comment fusionner les nouveautés de la branche "dev" dans "main" ?

  • git merge dev
  • git branch --merge dev
  • git checkout dev

3. Quelle commande permet de voir les URL GitHub liées à votre dépôt local ?

  • git remote --list
  • git config --url
  • git remote -v

4. Que fait exactement un "git pull" ?

  • Il télécharge et fusionne les modifications de GitHub dans le code local
  • Il efface la branche locale courante
  • Il envoie vos propres commits sur le serveur web

5. Comment afficher l'état de ses fichiers sous un format très court et résumé ?

  • git status --shortify
  • git status -s
  • git short-status

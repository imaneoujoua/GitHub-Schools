🔥 Commandes Avancées & Nettoyage

Maîtrisez la réécriture d'historique, l'annulation d'erreurs, le masquage de modifications et le marquage des versions de production.

A. Annulations, Modifications de Commits & Reset

1. Modifier le tout dernier commit

Permet d'ajouter des fichiers oubliés ou de corriger le message textuel du dernier commit sans en créer un nouveau.

git commit --amend -m "Nouveau message corrigé"

2. Annuler des commits en gardant les fichiers (Soft Reset)

Recule l'historique d'un commit en arrière. Vos modifications restent présentes et prêtes dans la zone de staging.

git reset --soft HEAD~1

3. Annuler TOUT et effacer les changements (Hard Reset)

⚠️ Attention : Recule l'historique et efface définitivement toutes vos modifications locales non enregistrées.

git reset --hard HEAD~1

4. Annuler proprement via un nouveau commit (Revert)

Crée un nouveau commit qui fait exactement l'inverse du commit ciblé (idéal et sécurisé pour le travail en équipe).

git revert
B. Remisage Temporaire (Stash) & Rebase

5. Masquer et mettre de côté son travail

Sauvegarde temporairement vos fichiers modifiés dans une boîte cachée pour nettoyer votre dossier sans faire de commit.

git stash

6. Récupérer son travail masqué

Restaure et réapplique les modifications précédemment mises de côté avec la commande stash.

git stash pop

7. Réécrire l'historique des branches (Rebase)

Déplace la base de votre branche actuelle pour la caler proprement juste après les tout derniers commits du main.

git rebase main
C. Gestion des Versions Importantes (Tags)

8. Créer un Tag de version

Pose un jalon permanent sur un commit pour marquer une étape majeure (ex: livraison finale de la version v1.0.0).

git tag -a v1.0.0 -m "Version stable 1.0.0"

9. Pousser les Tags vers GitHub

Les tags ne sont pas envoyés automatiquement. Cette commande force la synchronisation de vos repères de version sur GitHub.

git push origin --tags

Évaluation Expert

Validez vos compétences sur les situations complexes de Git.

1. Quelle option de "git reset" efface définitivement tous les changements locaux ?

  • --soft
  • --hard
  • --clean

2. Vous devez changer de branche en urgence mais votre code actuel n'est pas fini, que faites-vous ?

  • J'utilise "git stash" pour le mettre de côté en sécurité
  • Je supprime mes fichiers pour aller plus vite
  • Je fais un "git push --force"

3. Comment modifier le message textuel du tout dernier commit local effectué ?

  • git commit --change
  • git reset --message
  • git commit --amend

4. Quel outil permet de poser un repère nommé (ex: v1.0) sur l'historique stable de production ?

  • git tag
  • git bookmark
  • git branch -version
